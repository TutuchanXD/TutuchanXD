I build research-oriented tools around simulation, data analysis, and reproducible computation. Most of my public work sits at the intersection of Python workflows, C/C++ components, and astronomy/instrumentation-related experiments.

- Working on ET simulation and focal-plane related tooling
- Interested in scientific software, automation, and clean research workflows
- Prefer small, reliable utilities that make experiments easier to repeat
